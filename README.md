After thirteen years of waiting for GTA VI, the make.fun ghost hits Vice City with five wanted stars and a lumbar cushion in the getaway car. The scene was drawn from scratch in Pillow for the make.fun GTA 6 meme bounty.

## Post the meme

Attach [meme.png](meme.png) as the first image of a public X post from `@BRENKSEK270`. Paste the text block from [CAPTION.md](CAPTION.md) as the post text. Copy the published post URL into the `url` field of `POST.json` and keep the post public until results are out.

## Reproduce locally

Run `python3 gen-meme.py` with Pillow and the Noto Sans Display fonts installed at `/usr/share/fonts/truetype/noto`. To test the entrypoint with Node.js 22.18 or later, run `MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts` from the repository root.
